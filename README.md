Wazuh SIEM Home Lab – Nmap Scan Detection

Project Overview

This project demonstrates a home lab for Security Information and Event Management (SIEM) using Wazuh. The objective is to monitor endpoint activity and investigate potential network reconnaissance using Nmap.

Objectives

* Set up a Wazuh SIEM lab environment.
* Monitor endpoint security events.
* Simulate Nmap reconnaissance in an authorized lab.
* Investigate security alerts and understand their significance.

Tools and Technologies

* Wazuh SIEM
* Ubuntu Linux
* Nmap
* Oracle VirtualBox
* Networking and security log analysis

Lab Environment

* Wazuh Manager and Dashboard
* Monitored endpoint with a Wazuh agent
* Isolated or authorized lab network

Methodology

1. Configure the Wazuh Manager and endpoint agent.
2. Verify endpoint connectivity and event collection.
3. Run an Nmap scan against the authorized lab target.
4. Review the available events and alerts in Wazuh.
5. Analyze the results and document findings.

Results

Document the alerts actually observed during testing. Include screenshots of the Wazuh dashboard, agent status, Nmap scan, and relevant security events.

* Network reconnaissance analysis
